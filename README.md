# InvoiceFlow

InvoiceFlow is a Python-based invoice processing engine designed to automate the extraction, validation and organization of supplier invoices.

## Initial Features

- Extract information from text-based PDF invoices.
- Support scanned invoices through OCR.
- Identify key invoice information.
- Validate extracted data.
- Export invoice information to CSV and Excel.

## Initial Scope

The first version focuses exclusively on received supplier invoices.

The project starts as an independent Python engine, with the possibility of adding a desktop interface in the future.

## Technology

- Python 3.12+
- Pytest
